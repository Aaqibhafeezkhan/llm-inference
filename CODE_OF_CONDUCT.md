# Code of conduct

This repo is a place to learn how LLM inference systems work, so questions at every level are welcome.

- Be kind and patient. Assume good intent, and explain instead of judging.
- Keep review comments about the code and the maths, not the person.
- No harassment, insults or personal attacks, in issues, pull requests or anywhere else tied to this repo.
- Say where a number, a formula or an idea came from, and credit other people's work.

If someone breaks these rules, email the maintainer at bindubhargavareddy@gmail.com. Reports stay private. The maintainer may
edit or remove comments, lock threads, or block accounts that break these rules.
